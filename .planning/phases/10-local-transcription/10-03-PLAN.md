   ```typescript
   type ModelDownloadState = "idle" | "downloading" | "downloaded";
   const modelStates = ref<Record<string, ModelDownloadState>>({
     tiny: "idle", base: "idle", small: "idle", medium: "idle"
   });
   const downloadPercent = ref<Record<string, number>>({
     tiny: 0, base: 0, small: 0, medium: 0
   });
   const activeDownloadId = ref<string | null>(null);
   ```

2. Add imports: `import { listen } from "@tauri-apps/api/event";` and `import { onUnmounted } from "vue";`

3. In onMounted, hydrate initial state:
   ```typescript
   const downloaded = await invoke<string[]>("get_downloaded_models");
   for (const id of downloaded) {
     modelStates.value[id] = "downloaded";
   }
   ```

4. In onMounted, set up event listeners (store unlisten functions for cleanup):
   - `model-download-progress`: update `modelStates[payload.model_id] = "downloading"`, `downloadPercent[payload.model_id] = payload.percent`, `activeDownloadId = payload.model_id`
   - `model-download-done`: update `modelStates[payload.model_id] = "downloaded"`, `activeDownloadId = null`
   - `model-download-cancelled`: update `modelStates[payload.model_id] = "idle"`, `downloadPercent[payload.model_id] = 0`, `activeDownloadId = null`
   - `model-download-error`: same as cancelled + show error (console.error or a local error ref)

5. In onUnmounted, call all unlisten functions.

6. Add action functions:
   - `startDownload(modelId)`: call `invoke("start_model_download", { modelId })`
   - `cancelDownload()`: call `invoke("cancel_model_download")`
   - `deleteModel(modelId)`: call `invoke("delete_model", { modelId })`, then set `modelStates[modelId] = "idle"`
   - `setActiveModel(modelId)`: update config `transcription.providers.local.model_path` to the model path pattern (`ggml-{modelId}.bin` relative or absolute -- match what the Rust command saved), call saveConfig

7. Replace the template section for local model cards. For each model in LOCAL_MODELS:
   - **idle state**: Show model name, size, quality hint, and a "Download" button. Button is DISABLED if `activeDownloadId !== null` (another download in progress). Tailwind styling per Claude's discretion.
   - **downloading state**: Show model name, a full-width progress bar (Tailwind: `bg-blue-500` bar inside `bg-gray-200` track, `h-2 rounded-full`), percentage text (e.g. "47%"), and a "Cancel" button (red text). All other Download buttons disabled.
   - **downloaded state**: Show model name, size, quality, a green checkmark badge if this is the active model (`config.transcription.providers.local.model_path` contains this model id), a "Set Active" button (if not active), and a "Delete" button (trash icon or red text).

8. Keep the language hint selector below the local cards (it's already there outside the v-if block).

IMPORTANT: Event listener unlisten functions MUST be called in onUnmounted to avoid leaked listeners when Settings window is closed and reopened.
