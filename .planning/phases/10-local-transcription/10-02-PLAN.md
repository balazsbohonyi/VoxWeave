1. Create `src-tauri/src/transcription/download.rs`:

   Constants:
   ```rust
   pub const VALID_MODEL_IDS: &[&str] = &["tiny", "base", "small", "medium"];
   pub const MODEL_DOWNLOAD_PROGRESS_EVENT: &str = "model-download-progress";
   pub const MODEL_DOWNLOAD_DONE_EVENT: &str = "model-download-done";
   pub const MODEL_DOWNLOAD_CANCELLED_EVENT: &str = "model-download-cancelled";
   pub const MODEL_DOWNLOAD_ERROR_EVENT: &str = "model-download-error";
   ```

   Payload structs (derive Serialize, Clone):
   ```rust
   pub struct DownloadProgressPayload { model_id: String, percent: f32, bytes_done: u64, bytes_total: u64 }
   pub struct DownloadDonePayload { model_id: String, model_path: String }
   pub struct DownloadEventPayload { model_id: String, message: String } // for cancelled + error
   ```

   Helper functions:
   - `pub fn models_dir() -> Result<std::path::PathBuf, String>` -- `dirs_next::config_dir().ok_or("...")?.join("VoxFlow").join("models")`
   - `pub fn model_file_path(model_id: &str) -> Result<std::path::PathBuf, String>` -- validates model_id is in VALID_MODEL_IDS, returns `models_dir()?.join(format!("ggml-{model_id}.bin"))`
   - `pub fn model_download_url(model_id: &str) -> String` -- `format!("https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-{model_id}.bin")`
   - `pub fn get_downloaded_model_ids() -> Result<Vec<String>, String>` -- scan models_dir for `ggml-*.bin`, extract IDs, return sorted vec

   The async download function (called by commands, not itself a command):
   ```rust
   pub async fn run_download<R: tauri::Runtime>(
       app: tauri::AppHandle<R>,
       model_id: String,
       cancel: Arc<AtomicBool>,
   ) -> Result<String, String>
   ```
   - Create models_dir with `std::fs::create_dir_all`
   - Build reqwest client, GET the HF URL, read Content-Length
   - Stream chunks via `response.bytes_stream()` + `futures_util::StreamExt::next()`
   - Each chunk: write to file, update downloaded count, emit MODEL_DOWNLOAD_PROGRESS_EVENT with DownloadProgressPayload
   - Check `cancel.load(Ordering::Relaxed)` each chunk -- if true, drop file handle, delete partial file, emit MODEL_DOWNLOAD_CANCELLED_EVENT, return Err
   - On success: emit MODEL_DOWNLOAD_DONE_EVENT with model path, return Ok(model_path_string)
   - On any error: delete partial file, emit MODEL_DOWNLOAD_ERROR_EVENT, return Err
   - Use a partial file name during download (e.g. `ggml-tiny.bin.partial`) and rename to final name on success -- prevents half-written files from appearing as "downloaded"

   pub download_cancel: Arc<Mutex<Option<Arc<std::sync::atomic::AtomicBool>>>>,
   pub downloading_model: Arc<Mutex<Option<String>>>,
   ```
   Initialize both to `Arc::new(Mutex::new(None))` in both `Ok` and `Err` branches of `AppState::load()`.

1. Create `src-tauri/src/commands/download.rs` with four Tauri commands:

   **start_model_download(app, model_id: String) -> Result<(), String>:**
   - Guard: lock `downloading_model`, if Some(_) return Err("A download is already in progress")
   - Validate model_id is in VALID_MODEL_IDS
   - Create a new `Arc<AtomicBool>` cancel flag
   - Store cancel flag in `state.download_cancel` and model_id in `state.downloading_model`
   - Spawn download task via `tauri::async_runtime::spawn`:
     - Call `download::run_download(app.clone(), model_id.clone(), cancel.clone()).await`
     - On success: update config `transcription.providers.local.model_path = Some(path)`, save config to disk, clear downloading_model and download_cancel in state
     - On error (not cancelled): clear downloading_model and download_cancel
     - On cancelled: clear downloading_model and download_cancel (download::run_download already emits cancelled event and deletes file)
   - Return Ok(()) immediately (download runs in background)
   - IMPORTANT: Release MutexGuard before any .await -- clone what you need

   **cancel_model_download(state) -> Result<(), String>:**
   - Lock download_cancel, if Some(flag) set flag to true
   - The background task will detect this, clean up, and emit cancelled event

   **get_downloaded_models(state) -> Result<Vec<String>, String>:**
   - Call `download::get_downloaded_model_ids()`
   - Also check `state.downloading_model` -- if Some, include `{ id, status: "downloading" }` in response. Actually, keep it simple: return Vec<String> of downloaded model IDs only. The frontend tracks download-in-progress state via events.

   **delete_model(app, model_id: String) -> Result<(), String>:**
   - Validate model_id
   - Get file path via `download::model_file_path(model_id)`
   - If file exists, delete it
   - If `config.transcription.providers.local.model_path` points to this file, set it to None and save config
   - Return Ok

   ```
