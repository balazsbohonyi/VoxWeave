<objective>
Fix the two Rust-layer bugs that caused UAT gaps 1 and 3.

Gap 1: OpenAI Whisper rejects Ogg-encoded audio because `format_for_provider` routes OpenAI
to `EncodedFormat::Opus`, causing `openai.rs` to upload `audio.ogg` with MIME `audio/ogg`.
OpenAI Whisper requires WAV or MP3, not Ogg. Fix: route OpenAI to `EncodedFormat::Wav` and
update the filename/MIME in `openai.rs`.

Gap 3 (partial): `service.rs` Network match arms expose raw reqwest error strings
(e.g. "error sending request for url (https://...)") to the frontend toast.
Fix: replace with a friendly message "Network error. Check your connection and try again."

Purpose: These two fixes together unblock end-to-end transcription (gap 1) and make the
network-error toast human-readable (gap 3 message content).

Output: Modified encode.rs, openai.rs, service.rs — all Rust tests must still pass.
</objective>
