Current broken CSS (src/styles.css lines 202-212):
```css
.indicator-toasts {
  position: absolute;
  bottom: calc(100% + 8px);  /* BUG: places container ABOVE the window top edge */
  left: 0;
  right: 0;
  ...
}
```

Current `.indicator-root` (lines 11-23): uses `display: flex` but NO `position` declaration — defaults to `static`. This means `.indicator-toasts { position: absolute }` is currently anchored to the nearest positioned ancestor, which is `.indicator-pill` (position: relative) — but `.indicator-toasts` is a sibling of `.indicator-pill`, not its child, so absolute positioning relative to `.indicator-pill` behaves unexpectedly. To make `.indicator-toasts` overlay `.indicator-root` correctly, `.indicator-root` must be `position: relative`.

User-confirmed design decision: in-pill overlay — toast replaces pill content while active, renders within existing OS window bounds. No window resize. No positioning outside the window.

Make two targeted edits to src/styles.css:

**Edit 1 — Add `position: relative` to `.indicator-root`:**

In the `.indicator-root` rule (currently lines 11-23), add `position: relative;` after `display: flex;`. This makes `.indicator-root` the positioning context for the absolute `.indicator-toasts` child.

**Edit 2 — Replace `.indicator-toasts` positioning:**

Replace the current `.indicator-toasts` rule (lines 202-212):
```css
.indicator-toasts {
  position: absolute;
  bottom: calc(100% + 8px);
  left: 0;
  right: 0;
  display: flex;
  flex-direction: column;
  gap: 6px;
  pointer-events: auto;
  z-index: 100;
}
```

With:
```css
.indicator-toasts {
  position: absolute;
  inset: 0;
  display: flex;
  flex-direction: column;
  align-items: stretch;
  justify-content: center;
  gap: 6px;
  pointer-events: auto;
  z-index: 100;
  padding: 4px;
  box-sizing: border-box;
}
```

`inset: 0` means `top: 0; right: 0; bottom: 0; left: 0` — the toast container covers the full window area (same as the pill) but renders within the OS window rectangle, bypassing the compositor clipping issue. `padding: 4px` gives the inner toast a small breathing margin from the window edge. `justify-content: center` vertically centers the toast within the pill height.

Do NOT change `.indicator-toast`, `.indicator-toast--error`, `.indicator-toast-message`, `.indicator-toast-action`, or `.indicator-toast-dismiss` — those styles are correct.

Do NOT change any Vue template files — the DOM structure is already correct.
