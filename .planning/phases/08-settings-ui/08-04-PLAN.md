Active mode is derived from `config.transcription.provider === 'local'`. Clicking "Cloud" sets active provider to `config.transcription.provider` (don't change it if it's already openai/groq). Clicking "Local" calls `saveConfig({ transcription: { ...config.transcription, provider: 'local' } })`.

**Provider tabs (Cloud mode):**
Two tabs: "OpenAI" and "Groq". Tab bar renders both; clicking a tab sets `activeTab`.
Active provider badge: show a small "Active" badge or blue accent border on the tab that matches `config.transcription.provider`.

**Per-tab content (repeated for each tab, conditional on activeTab):**
1. API key row: label "API Key" + `<input type="password" v-if="!showApiKey[tab]" / type="text" v-else>` bound to local draft ref. Eye icon button toggles `showApiKey[tab]`. Save on blur: `saveConfig` with deep spread (see interface above). Clear `testConnectionState[tab]` to 'idle' on any edit.
2. Model dropdown: `<select>` bound to local model draft, options from `providerModels.openai` or `.groq`. Save on change: deep spread into `providers.<tab>.model`.
3. "Test connection" button: on click, set `testConnectionState[tab] = 'pending'`, invoke `test_connection`, on success set 'success' + message "Connected", on error set 'error' + error string. Show spinner icon during 'pending', green checkmark during 'success', red x during 'error'. Clear after next edit.
4. Inline test result: `<span v-if="testConnectionState[tab] !== 'idle'">` below the button.
5. "Set as active" button: disabled if this tab's provider is already active. On click: `saveConfig({ transcription: { ...config.transcription, provider: activeTab.value } })`.
6. Language hint: `<LanguageSelect>` bound to `config.transcription.language`, save on change via `saveConfig({ transcription: { ...config.transcription, language: newLang } })`. This is a global field, rendered once (outside the per-tab block or inside — place it below the tabs since it's global).

**Local draft refs for API key and model:** Use `watch(config, ...)` to sync local draft refs when config loads. This follows the pattern from RESEARCH.md: "Never v-model on config directly".

```typescript
const openaiKeyDraft = ref('');
const groqKeyDraft = ref('');
const openaiModelDraft = ref('');
const groqModelDraft = ref('');

watch(config, (cfg) => {
  if (!cfg) return;
  openaiKeyDraft.value = cfg.transcription.providers.openai.api_key;
  groqKeyDraft.value = cfg.transcription.providers.groq.api_key;
  openaiModelDraft.value = cfg.transcription.providers.openai.model;
  groqModelDraft.value = cfg.transcription.providers.groq.model;
}, { immediate: true });
```

Use `@blur` on key inputs to save (not `@input` — avoid saving on every keystroke for API keys). Use `@change` on model dropdowns (saves immediately).
