# Phase 05.1 Plan 06: Language Selector in Settings Summary

**Language setting exposed in Settings window as a searchable autocomplete dropdown covering all 99 Whisper-supported languages**

## Background

The `transcription.language` field existed in `AppConfig` and was already forwarded to the Whisper API, but had no UI — users had to hand-edit `config.json` to set it. Leaving it empty (`""`) causes Whisper to auto-detect the spoken language, which sometimes misidentifies short or accented audio and returns text in the wrong language.

## Accomplishments

- Created `LanguageSelect.vue` — custom autocomplete component with:
  - Text input that filters 99 languages by name or BCP-47 code as the user types
  - ArrowUp / ArrowDown keyboard navigation through filtered results
  - Enter to confirm, Escape to dismiss and restore previous value
  - Auto-detect option always at the top (maps to `""`)
  - First filtered match auto-highlighted while typing so Enter immediately picks the right language
  - Saves to config on selection (no explicit Save button)
- Wired `LanguageSelect` into `Settings/App.vue` replacing the previous 15-language `<select>`
- TypeScript typecheck passes with no errors

## Files Created/Modified

- `src/windows/settings/components/LanguageSelect.vue` — new autocomplete component (99 languages)
- `src/windows/settings/App.vue` — replaced `<select>` with `<LanguageSelect>`, simplified `saveLanguage()`

## Decisions Made

- Empty string (`""`) = Auto-detect, consistent with the existing backend behaviour (language field omitted from Whisper API call when empty)
- `mousedown.prevent` used on list items so the input's `blur` handler fires after the click is processed, preventing the dropdown from closing before the selection registers
