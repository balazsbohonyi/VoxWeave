`src/windows/settings/main.ts` — replace entire file content with:

import { attachConsole } from "@tauri-apps/plugin-log";

createApp(App).mount("#app");

`src/windows/indicator/main.ts` — replace entire file content with:
```typescript
import { attachConsole } from "@tauri-apps/plugin-log";
import { createApp } from "vue";
import "../../styles.css";
import App from "./App.vue";

await attachConsole();
createApp(App).mount("#app");
```

Notes:
- Top-level `await` is valid because both entry points are ES modules (Vite + `"type": "module"` in package.json).
- `attachConsole()` returns `Promise<UnlistenFn>`. We deliberately ignore the return value — there is no cleanup needed for an app-lifetime listener.
- Place the import BEFORE the `createApp` import for import ordering clarity, but Vite handles any order.
- Do NOT add error handling for `attachConsole()` — a failure to attach the console is non-fatal and should not prevent the app from rendering.
