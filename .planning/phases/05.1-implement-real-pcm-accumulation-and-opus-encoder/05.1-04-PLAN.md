  <name>Task 1: Show toast in hotkey Err arm for short-recording (and other encode errors)</name>
  <files>src-tauri/src/hotkey/service.rs</files>
  <action>
In `src-tauri/src/hotkey/service.rs`, locate the `Err(err)` arm of the
`audio::stop_recording_and_encode(app)` match (currently around lines 251-257).

Replace:
```rust
Err(err) => {
    log::warn!("Failed to finalize recording: {err}");
    indicator::hide(app);
    let state = app.state::<AppState>();
    *state.recording_state.lock().unwrap() = RecordingState::Idle;
    tray::update_recording_menu(app, RecordingState::Idle);
}
```

With:
```rust
Err(err) => {
    log::warn!("Failed to finalize recording: {err}");
    let state = app.state::<AppState>();
    *state.recording_state.lock().unwrap() = RecordingState::Idle;
    tray::update_recording_menu(app, RecordingState::Idle);
    // Show the error as a toast in the indicator overlay.
    // show_toast_window positions, shows, and hides the indicator itself.
    // Use TranscriptionErrorPayload because that is what the toast JS expects.
    let payload = transcription::service::TranscriptionErrorPayload {
        code: transcription::service::TranscriptionErrorCode::TooShort,
        message: err.clone(),
        provider: None,
        fallback_provider: None,
        retryable: false,
    };
    if let Err(toast_err) = indicator::show_toast_window(app, &payload) {
        log::warn!("Failed to show error toast: {toast_err}");
        // Fallback: hide the indicator so it is not left dangling.
        indicator::hide(app);
    }
}
```

Ensure `transcription::service` is imported at the top of `hotkey/service.rs` if it
is not already. Check existing `use crate::transcription` imports and add
`use crate::transcription::service::{TranscriptionErrorCode, TranscriptionErrorPayload};`
(or the equivalent `crate::transcription::service::*` pattern already present).

Do NOT remove the `indicator::hide(app)` from the fallback path — it is the safety
net when `show_toast_window` itself fails.
